Pipeline detail

Generative
Deterministic
01
Ingest & chunk Deterministic

Async client against ClinicalTrials.gov API v2 — token-bucket rate limiting, pagination, incremental sync. Chunking is domain-aware: eligibility criteria packed whole (no split/overlap — atomic units), prose recursively split with overlap. Verified with property-based tests (Hypothesis) + real-data regression tests.

02
Embed & index Deterministic

Voyage voyage-4-lite, Matryoshka-truncated to 512 dims, content-hash cached. Bulk-loaded into Postgres/pgvector as halfvec(512) with combined HNSW + GIN indexes.

03
Parse query → filters Claude structured output

NL question → structured filters (phase/status/age/sex). Condition/keyword terms kept as free text deliberately, to avoid dropping paraphrases. Age filtering is interval-overlap logic against eligibility ranges, not equality.

04
Hybrid retrieve & fuse Deterministic

One SQL statement, three CTEs: metadata pre-filter → dense HNSW cosine + sparse full-text → Reciprocal Rank Fusion. Dense-only 0.962 recall@1, sparse-only 0.048, fused hybrid 0.990.

05
Rerank & diversify Voyage rerank-2.5-lite Diversity cap

Cross-encoder re-score of fused candidates, capped per-study so one heavily-chunked trial can't dominate the result set.

06
Generate with citations Claude

Chunks passed as isolated document content blocks, never string-interpolated — this is the prompt-injection containment mechanism, verified live against a real injection attempt. Prompt caching on the last block; citations resolve via document_index back to source chunk. Haiku screens off-topic/jailbreak queries before this call runs; system prompt enforces abstention and refuses medical advice.

CI/CD & infrastructure

Terraform-managed AWS. Every PR is quality-gated on retrieval regression, not just tests passing.

Production incidents — root causes

  • OIDC trust-policy claim mismatch — GitHub's OIDC token claims didn't match the IAM trust policy's condition keys; blocked CI deploys until corrected.
  • ECR tag-immutability conflict — BuildKit caching collided with ECR's immutable-tag setting; fixed by changing the tagging strategy.
  • IAM PassRole gap — App Runner's deploy role lacked permission to pass its own running-task role; surfaced only at deploy time.
  • Budget-alarm threshold bug — CloudWatch billing alarm fired at 30x the intended spend threshold.
  • Client-side SSE parsing bug — sse_starlette terminates frames with \r\n\r\n; frontend's buffer.indexOf("\n\n") could never match inside that string, so every response buffered forever and rendered nothing. Backend logs showed correct completion both times. Root-caused with a headless browser tracing the parser — curl-based testing never caught it, since curl doesn't execute JS. Fix: /\r?\n\r?\n/ regex accepting either line ending.

Engineering rigor

  • mypy --strict + ruff (incl. bandit security rules), clean and enforced in CI.
  • Two-tier eval — deterministic recall/MRR/nDCG (pure numpy, seconds per PR) + LLM-as-judge scoring for faithfulness/completeness on generated answers.
  • Load tested with k6 against the streaming query path.
  • OpenTelemetry tracing across retrieve → rerank → generate.
  • ADRs: Postgres over Pinecone/Qdrant (metadata filters need to share the vector search's query plan), no LangChain/LlamaIndex (SQL + Anthropic calls are simple enough that a framework adds indirection without payoff), App Runner over Lambda/Fargate.
  • Resilience drills beyond the production rollback test, exercising dependency-failure behavior.
